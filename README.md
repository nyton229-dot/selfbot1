# VK бот-фильтр мата (для сообщества)

Асинхронный бот сообщества на [vkbottle](https://github.com/vkbottle/vkbottle), который следит за беседами и автоматически модерирует нецензурную лексику.

## Как работает

1. Бот слушает сообщения бесед через Bots Long Poll в реальном времени.
2. **Обычные сообщения не трогает** — никакой реакции.
3. Если в сообщении найден мат:
   - мгновенно удаляет оригинал для всех (`delete_for_all=1`);
   - отправляет в тот же чат копию от имени бота в формате:

     ```
     Имя Фамилия: <оригинальный текст сообщения>
     ```

     Текст пересылается как есть, без цензуры. Имя автора — кликабельная ссылка на его профиль. Если удаленное сообщение было ответом (реплеем) на чье-то сообщение — бот отправит свою копию реплеем на то же сообщение, чтобы контекст не терялся. Вложения пересылаются вместе с текстом: фото, GIF, документы и голосовые бот перезаливает от имени группы (чужие вложения по строке VK у ботов молча выбрасывает), видео уходит ссылкой (VK разворачивает ее в плеер), музыка — строкой с исполнителем и названием.

## Команды

- `!ник <новый ник>` — сменить имя, которым бот подписывает твои пересланные сообщения (остается ссылкой на профиль);
- `!ник` — показать текущий ник и подсказку;
- `!ник сброс` — вернуть настоящее имя;
- `!мат <слово>` — добавить свое запрещенное слово (только админ беседы); бот будет удалять сообщения с ним, маскировка (`пр1вет`, `п р и в е т`) не спасет;
- `!мат удалить <слово>` — убрать слово из списка (только админ);
- `!мат список` — показать свой список;
- `!н` — показать администратора бота (ссылка на профиль для связи по вопросам о боте);
- `Кто я` (синонимы: `!роль`, `Профиль`, `Анкета`, `хто я`) — анкета вызвавшего: имя, ник, роль, сколько сообщений написал и сколько удалено за мат. Отправь реплеем на чужое сообщение — покажет анкету того участника;
- `Кто ты` — анкета указанного пользователя: ответь реплеем на его сообщение или добавь ссылку (`Кто ты vk.com/id123`, работает и с короткими именами);
- `!варн` (реплеем или со ссылкой) — предупреждение; 3/3 — автоматический кик из беседы. Снять: `!варн снять` (только админ);
- `!мут 10м` (реплеем или со ссылкой) — мут: бот удаляет все сообщения участника. Время: `30с`, `10м`, `2ч`, `1д`, по умолчанию 10 минут. Снять: `!размут` (только админ);
- `Стата` (или `!стата`) — статистика беседы: всего сообщений, удалено за мат, предупреждения, муты и топ-5 активных и нарушителей.

Главный админ бота (ID указан в `BOT_OWNER_IDS` в `bot.py`, можно дополнить через переменную окружения `BOT_OWNER_IDS=123,456`) может управлять ботом в любой беседе, даже не будучи админом самой беседы.

Ники, свои слова, статистика и муты хранятся в папке `data/` (файлы `nicknames.json`, `custom_words.json`, `stats.json`, `mutes.json` создаются автоматически) и не слетают при перезапуске. На Bothost папка `data/` постоянная и переживает переустановку контейнера. Ник с матом поставить нельзя.

## Обход маскировки

Фильтр распознает мат, даже если его пытаются спрятать:

- латинские буквы-двойники и цифры: `нaхуй`, `cyka`, `п0шел`, `6ля`, `xуй`;
- спецсимволы внутри слова: `х*й`, `б#лядь`, `х@й`, `п.и.з.д.е.ц`;
- полностью скрытые буквы — сверка со словарем по маске: `с**а`, `пи**ец`;
- растянутые буквы: `сууукаааа`;
- написание по буквам: `х у й`, `с у к а`.

При этом обычные слова с «опасными» корнями не трогаются: *команда, потребляет, хлеб, скипидар, учебную, судебную, психуй, педикюр* и т.п. (фильтр прогнан по списку из 50 000 самых частотных русских слов).

## Настройка сообщества

1. **Токен**: Управление сообществом → Работа с API → Ключи доступа → создать ключ с правом **«сообщения сообщества»**.
2. **Long Poll**: Работа с API → Long Poll API → включить, версия API 5.199 (или свежая); во вкладке «Типы событий» отметить **«Входящее сообщение»**.
3. **Сообщения**: Сообщения → включить; Настройки для бота → включить **«Возможности ботов»** и разрешить добавлять бота в беседы.
4. **Добавить бота в беседу** (через меню беседы) и **назначить администратором беседы** — без этого VK не разрешит удалять чужие сообщения.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # и вписать токен
python bot.py
```

В `.env` нужен один параметр:

```env
VK_GROUP_TOKEN=токен_сообщества
```

Если все ок, в логе появится:

```
Бот-фильтр мата запущен и слушает сообщения...
```

## Важно: права администратора беседы

Чтобы удалять **чужие** сообщения, бот должен быть **администратором беседы**. Если прав нет, бот не упадет: он запишет ошибку в лог и раз в 5 минут предупредит в чате, что не может удалить сообщение.

Также по правилам VK удалить сообщение для всех можно только в течение 24 часов после отправки (для бота это не проблема — он реагирует мгновенно).

## Тесты фильтра

```bash
python test_profanity_filter.py
```

## Настройка словаря

Весь словарь лежит в `profanity_filter.py`:

- `PROFANITY_ROOT_PATTERNS` — регулярки-корни мата;
- `FALSE_POSITIVE_FRAGMENTS` — обычные слова, которые нельзя трогать;
- `MASKED_DICTIONARY` — явный список слов для сверки по маске (`х*й`);
- `HOMOGLYPH_MAP` — таблица букв-двойников.

## Деплой на Bothost.ru (24/7)

1. Залей код в GitHub/GitLab (в репозиторий не попадает `.env` — он в `.gitignore`).
2. Создай проект на [bothost.ru](https://bothost.ru/), платформа **VK**, укажи Git URL и ветку.
3. В переменных окружения добавь `VK_GROUP_TOKEN`.
4. Запусти деплой — `Procfile` стартует `bot.py` автоматически.
